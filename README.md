# Excel Business Analytics

This repository contains Microsoft Excel projects focused on business analytics, financial modeling, operational reporting, spreadsheet automation, and decision-making tools developed through coursework and business analytics projects.

The projects demonstrate spreadsheet-based analytical problem solving using Excel for operational and business applications.
